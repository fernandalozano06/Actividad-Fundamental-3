# Sistema FitZone — Diseño Arquitectural

## Empresa

FitZone es una empresa del sector del acondicionamiento físico que ofrece servicios de gimnasio y clases grupales. Este proyecto propone el diseño arquitectural de un sistema de software para gestionar reservaciones, membresías, accesos, asistencias y listas de espera.

## Alcance

El sistema contempla la consulta de clases, la gestión de reservaciones y cancelaciones, la validación de membresías y planes, el control de capacidad, las listas de espera, el registro de asistencias y no-shows, y la administración de clases.

También considera las notificaciones a los socios y los indicadores de ocupación.

Quedan fuera del alcance los pagos, la contratación y modificación de membresías, la nómina, la contabilidad y la gestión completa de entrenamientos personalizados.
